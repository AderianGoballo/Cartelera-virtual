PROCESO ACTIVO 2026

Proceso Online — Art. 25

Aspirantes aprobados Evaluación Deportiva 2026

Completa cada una de las etapas a continuación en el orden indicado. Este espacio está diseñado exclusivamente para los aspirantes que superaron la fase de evaluación deportiva presencial.

Paso 1

Video de Instrucciones

Antes de continuar con el proceso, mira detenidamente este video. En él encontrarás todas las indicaciones sobre cómo completar cada etapa del proceso online del Artículo 25 año 2026.

Si tienes problemas para reproducir el video, asegúrate de haber iniciado sesión con tu cuenta de Google o ábrelo en una nueva pestaña.
Paso 2

Láminas del Taller

Revisa el archivo PDF con las láminas del taller. Tómate el tiempo necesario para leer y comprender cada diapositiva antes de continuar.

Si tienes problemas para visualizar el documento, puedes descargarlo aquí.
Paso 3

Tareas Asignadas

A continuación encontrarás las láminas y las infografías con las tareas que debes realizar. Lee cuidadosamente el documento. Haz clic en las infografías para ampliarlas.

📋 Tarea 1: ¡Este Soy Yo!
📋 Tarea 2: Valores
📋 Tarea 3: Personajes
📋 Tarea 4: Ruta Académica

🖼️ Haz clic en cada infografía para ampliarla.

Paso 4

Tests a Realizar

Debes completar los siguientes tests psicológicos y vocacionales. Es necesario que inicies sesión con tu cuenta de Google para poder realizarlos y que tus resultados queden registrados.

Inicia Sesión para acceder

Debes autenticarte con tu cuenta de Google para realizar los tests y guardar tus respuestas.

Test IPP

Inventario de Intereses y Preferencias Profesionales. Descubre tu vocación y preferencias de carrera.

Realizar test

Autopercepción Vocacional

Evaluación de la influencia en las decisiones vocacionales y profesionales del aspirante.

Realizar test

Test CASM-85

Inventario de Hábitos de Estudio. Descubre y mejora tus técnicas de aprendizaje y rendimiento.

Realizar test
Paso 5

Entrevista Guiada

La última etapa es la entrevista guiada. Debes completar el formulario a continuación con honestidad y con toda la información requerida. Este formulario es confidencial y es parte del proceso de admisión.

Formulario de Entrevista Guiada

Al hacer clic en el botón serás redirigido al formulario de Google. Complétalo con todos tus datos y responde cada pregunta con la mayor precisión posible.

⏱️ Tiempo estimado: 15–25 minutos

Completar Entrevista Guiada

Si tienes problemas para acceder al formulario, escríbenos a daiadducv@gmail.com

Importante: completa todos los pasos

Para que tu proceso esté completo debes haber: visto el video, revisado las láminas, realizado las tareas, completado los 3 tests y respondido la entrevista guiada. El incumplimiento de cualquier etapa puede afectar tu proceso de admisión.

Paso 6

Envío de Información

Una vez completados todos los pasos anteriores (tareas, tests, y entrevista), debes enviar un correo electrónico confirmando la culminación de tu proceso online.

Instrucciones para el Correo

  • Destinatario: daiaarticulo25@gmail.com
  • Asunto del correo: Culminación Proceso Art. 25 - [Tu Nombre y Apellido] - [Tu Disciplina Deportiva]
  • Cuerpo del mensaje: Indica tu nombre completo, número de cédula, disciplina deportiva y confirma que has realizado todas las asignaciones, los tests y la entrevista.
  • Adjuntos: Si alguna de las tareas o láminas requería un archivo o captura de pantalla, adjúntalo en este mismo correo.
